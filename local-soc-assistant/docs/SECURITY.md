# Безопасность и автономность

## Рабочий режим

Анализ принимает только локальный путь GGUF, локальный STIX и SQLite-индекс.
Нет HTTP-клиента модели, платного API, выполнения кода, функций блокировки, удаления,
реагирования или сканирования. Командные строки журналов никогда не исполняются.
`prepare.py` не вызывается анализатором. Модель не получает tools/function calling.

До анализа устанавливаются offline/telemetry переменные. Python audit hook запрещает
внешний socket connect/getaddrinfo/sendto/bind и допускает loopback для UI.
Streamlit analytics отключена; JS/CSS интерфейса поставляются с установленным пакетом.
Оригинальные события не записываются в консольные диагностические сообщения.
Промпты/ответы хранятся локально в истории для аудита и могут содержать чувствительные данные.

**Ограничение:** audit hook не является границей OS-изоляции и не перехватывает произвольную
сеть из native-библиотеки. Рантайму передаются только локальная модель и генерация;
native-сборка в проверочной Linux-среде собрана без CURL. Не заявляется абсолютная защита.
Для строгого офлайн-испытания физически отключите сеть или примените штатную политику Windows
к используемому интерпретатору, а затем выполните Check.ps1 -RealLLM и анализ в UI.
Приложение не меняет самостоятельно сетевые адаптеры/брандмауэр и не требует администраторских прав.

## Недоверенные данные

Входные события и RAG-фрагменты находятся в отдельном user-сообщении с маркировкой недоверенных данных.
Это снижает риск подмены инструкций, но само по себе не гарантирует устойчивость LLM.
Сценарии с «IGNORE ALL INSTRUCTIONS» и HTML включены в корпус.
Защита результата D основана на детерминированных ссылках/профилях и ограниченном наборе рекомендаций,
а не на предположении, что модель всегда соблюдает системный промпт.

UI использует st.text/st.code/st.json для недоверенных значений, без unsafe_allow_html.
HTML-экспорт экранирует значения и содержит CSP без script/network ресурсов.
Ссылки на доказательства — внутренние якоря; внешние ссылки источников выводятся как текст.
Никакая команда из события не запускается даже при корректном ATT&CK ID.

## Процесс и локальный доступ

Запускайте от обычной учётной записи Windows. Сервер доступен на 127.0.0.1,
включена XSRF-защита. Это однопользовательский прототип без полноценной аутентификации.
Другой пользователь с доступом к файловой системе может читать/изменять данные и конфигурацию;
это ограничение локальной модели угроз. Для реальной эксплуатации нужны ACL, управление ключами,
политики хранения/удаления, резервное копирование и независимый аудит.

Файлы ограничены размером/вложенностью/длиной полей, неизвестные поля сохраняются в оригинале.
Не открывайте чувствительные журналы на совместно используемой машине.
Импортируемый файл не используется как путь сохранения: оригинал записывается по SHA-256.
